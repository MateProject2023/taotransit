# Базовые токены MATE

Выжимка дизайн-системы Mate & Partners для переноса на соседние направления.
Только примитивы: цвет, шрифт, форма, ритм, движение. Компонентов здесь нет
намеренно — они у каждого направления свои.

- `tokens.css` — готов к вставке, чистые CSS-переменные, без зависимостей
- `tokens.json` — то же самое машиночитаемо, с пометками где что применять
- `craft-font.css` + `fonts/` — гарнитура (woff2 + woff), если её ещё нет в проекте

## Подключение

Обычный проект:

```css
@import './tokens.css';
```

Tailwind 4 — перенести значения в `@theme`, имена свои:

```css
@theme {
  --color-brand: #2C3192;
  --color-paper: #F9FAFD;
  --font-craft: 'craftworksans', ui-sans-serif, system-ui, sans-serif;
}
```

Tailwind 3 — те же значения в `theme.extend` в `tailwind.config.js`.

## Пять правил, без которых токены рассыпаются

**Серый не бывает текстом.** Фирменный `#8D8F99` даёт на светлом фоне
3.09:1 и проваливает WCAG AA. Он только для линий, рамок и разделителей.
Для вторичного текста есть `--muted` (5.07:1) и `--muted-on-brand` (6.10:1),
выведенные из него затемнением в том же тоне.

**Фон не чисто белый.** `--paper` подмешивает брендовый тон. Благодаря этому
белая карточка на нём читается приподнятой без единой тени. Замените
`--paper` на `#FFFFFF`, и придётся возвращать тени.

**Иерархия строится массой.** Одна гарнитура, разрыв между соседними
ступенями минимум в две ступени веса и в 1.5 раза по размеру. Начертание
500 не подключается вовсе: 600 над 700 это не иерархия, а шум.

**Красный свой, не из Tailwind.** `red-600` даёт на `--paper` 3.49:1.
Используйте `--alert`.

**Тени только в ответ на действие.** В покое поверхности плоские.
Если элемент отбрасывает тень, не будучи наведённым или сфокусированным,
тень лишняя.

## Что перенастроить под другое направление

Цветовая стратегия задаётся тем, **сколько поверхности отдано брендовому**,
а не самим цветом. В Mate & Partners это 30–60% вертикали: секции целиком
чередуются между `--paper` и `--brand`. Если направлению нужен более
спокойный тон, уменьшите долю брендовых секций, но не разбавляйте сам цвет.

Размеры даны для базовой ширины макета 1440. Если в проекте корневой размер
шрифта фиксированный (16px), шкала работает как есть. Если пропорциональный
вьюпорту, как на matestrade.com, значения считаются против той же базы.
